
# Scholarship Finder
A Kivy-based scholarship finder application designed to help students discover and manage scholarship opportunities.

## Features

- Scholarship database
- Advanced scholarship filters
- Personal student profile
- Scholarship matching score
- Application status tracker
- Documents checklist
- Deadline tracking
- Deadline reminders
- Official scholarship links

## Technology

- Python
- Kivy
- JSON

## Run

Install Kivy and run:

python main.py

## Purpose

This project helps students organize scholarship opportunities and track their scholarship applications in one place.
